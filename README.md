# SimpleStock — Descargas

Instaladores de **SimpleStock**, el sistema de gestión para maxikioscos.

Este repositorio solo tiene los instaladores publicados: el código del sistema no está acá.

## Descargar

La última versión está en [Releases](../../releases/latest): bajá el archivo
`Instalar-SimpleStock-<versión>.exe` y abrilo en la computadora principal del comercio.

- **Actualizar** es abrir el instalador de la versión nueva: conserva ventas, productos, usuarios,
  licencia, respaldos y configuración.
- **Volver a una versión anterior**: en el menú Inicio, «SimpleStock - Volver a la versión anterior».
  Si no está, bajá de [Releases](../../releases) el instalador de la versión que quieras y abrilo.

SimpleStock avisa solo, a quien administra, cuando hay una versión nueva publicada acá.
